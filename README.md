# Security-Log-Analyzers

SECURITY LOG ANALYSIS & THREAT DETECTION SYSTEM
Author: Roshaan Ameer
Purpose: Enterprise-grade security log analyzer for threat detection and incident response
Repository: github.com/roshanameer/security-log-analyzer

WHAT THIS DOES:
- Processes 1,000+ security log entries in real-time
- Detects brute force attacks, port scanning, and suspicious IP behavior
- Generates risk scores (1-10 scale) and professional reports
- Exports to JSON and CSV for SIEM integration
- Demonstrates SOC (Security Operations Center) capabilities
